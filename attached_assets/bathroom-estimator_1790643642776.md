# HBUILD bathroom estimating reference

Use for HBUILD bathroom requests. These are user-supplied rates, not verified market rates. Later user clarification overrides unresolved assumptions below.

## Package and measurements

Standard installation package source: https://www.homedepot.com/list/view/details/shared/c6bf3e10-b217-11f1-a0c7-8b6134acb95f . Contents and prices were inaccessible through the web tool; do not invent or claim an import. Verify/import products or accept a user-supplied list, store source and price date, and map each item to fixed/area/count quantities. Avoid duplicates with automatic tile/backerboard lines.

Tub Yes/No; capture size and drain side for a tub. Proposed branch is no new shower-pan entry when Tub Yes; allow pan entry for a shower when Tub No. Keep old demolition and new assembly independent for conversions. Confirm this interpretation if required to implement.

Collect wall SQFT and wall height separately. Demo Tile Surround costs $4/SQFT. Pan demo costs $9/SQFT of confirmed demolition footprint. New installation area can default from entered wall area but must be editable even without demolition.

User requested drywall-to-drywall pan dimensions with a 1-inch subtraction; which dimensions/per-side treatment and demo applicability remain unresolved. Preserve raw measurements and require an explicit adjustment policy. If confirmed as subtracting 1 inch total from both horizontal dimensions in inches: area = (width - 1) × (depth - 1) / 144. This is estimating logic, not verified purchasing fit.

5 × 3 ft backerboard covers 15 SQFT: sheets = ceiling(new wall SQFT / 15), with any explicitly configured waste before rounding. Tile takeoff equals new wall SQFT before configured waste/box rounding. Do not multiply already entered SQFT by wall height. No default waste is authorized. Board/tile prices, installation, waterproofing, tub/pan work, and disposal need supplied pricing or explicit scope resolution.

## Finishes and optional work

- Shower trim: Brushed Nickel, Stainless, Chrome, Matte Black, Brushed Gold. No invented finish surcharge.
- Supplied statement “shower valve $380 Fixture Price $750 Install Price” has ambiguous allocation. Candidate $380 material + $750 installation is not confirmed. Clarify before activating rates.
- Niche Yes/No; capture size/count, require missing material/labor pricing.
- Drywall No = no charge; Yes requires mutually exclusive Simple touchups $535 or Other repair $1,600. Proposed per-bathroom fixed allowance; labor/material allocation and scope basis remain unconfirmed.
- Existing vanity width; Replace Vanity Yes/No; new widths 24, 30, 32, 34, 36, 38 inches or custom.
- Replacing vanity adds one P-trap plumbing allowance $130 (labor/material coverage unresolved) and one faucet $250 combined labor/material. Default one sink; multiplication per sink is an explicit proposed assumption. Vanity supply and cabinet installation/removal remain separate and unpriced unless configured. Permit independent fixture replacement without cabinet replacement.
- New vanity light $75 installation labor each; material separate.
- Towel bar $25 labor each; material separate.
- Mirror $125 installation labor each; material separate.
- Additional light $375 combined labor/material each; do not charge this and vanity-light labor for the same work.

## Reconciliation and completeness

Use inherited additive markup assumption (35% + 20% + 50% + 7%; cost × 2.12) once, with tax separate. Preserve combined allowances without inventing cost splits. Pending package contents, dimensional rules, fixture allocation, and installation rates are completeness issues, not zero prices. Save drafts but do not issue incomplete totals as complete quotes.
